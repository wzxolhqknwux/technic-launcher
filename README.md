## Overview

The Technic Launcher is the foundational Minecraft modpack launcher built around the Technic platform and Solder API, enabling one-click installation of thousands of community-curated modpacks including Tekkit Classic, Hexxit, Crazy Craft, and Attack of the B-Team. It handles Java management automatically and supports self-hosted private modpacks via Technic platform URLs for server communities.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Technic Launcher** delivers the features you need in a clean, intuitive package.

> Official website: [technicpack.net](https://technicpack.net)

| Feature | Description |
|---------|-------------|
| **Technic Modpack Library** | Thousands of community modpacks from the Technic platform catalog |
| **One-Click Install** | Automatic Java download and modpack installation in a single click |

| **Private Packs** | Host and share private modpacks via custom Technic platform URLs |
